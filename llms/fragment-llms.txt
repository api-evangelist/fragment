# Fragment

> Fragment is the ledger API for engineers who move money — a double-entry accounting engine ("the database for money"). Model any funds flow as a declarative, typed chart-of-accounts schema, post balanced idempotent ledger entries over GraphQL, and read real-time, historical, period, and strongly-consistent balances across multi-currency accounts. OAuth2 client-credentials auth, typed GraphQL union errors, cursor pagination, AWS regional deployments. Used by Bill, Ramp, Pleo, AtoB, Basic Capital, and Nala; backed by General Catalyst.
